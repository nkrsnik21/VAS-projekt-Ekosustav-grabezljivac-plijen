
Kratki sažetak aplikacije
Projekt implementira višeagentni simulacijski model u kojem svaki agent predstavlja pojedinačnu jedinku vrste plijena ili grabežljivca koja se kreće kroz prostorno podijeljeno stanište, traži hranu, razmnožava se i umire ovisno o lokalnim uvjetima. 
Agenti su modelirani kao reaktivni konačni automati koji u dinamičnom, stohastičnom i neepizodičnom okruženju donose odluke na temelju svojeg trenutnog stanja (energija, dob, lokacija) i stanja okoline (dostupnost resursa, prisutnost predatora/plijena). 
Cilj simulacije je analizirati kako promjene u parametrima (npr. brzina regeneracije resursa, vjerojatnost migracije, intenzitet predacije) utječu na dugoročnu stabilnost ekosustava, oscilacije populacija i rizik izumiranja vrsta.


Na ovom repozitoriju priložena je dokumentacija koja je izrađena u svrhu kolegija Višeagentni sustavi na Fakultetu organizacije i informatike.
Dokumentacija sadrži glavnu python skriptu pod nazivom vas.py koja pokreće izrađen program.
Za pokretanje programa potrebno je ui terminalu upisati python vas.py nakon čega se otvara skočni prozor s defaultno unesenim podacima koji se mogu i promijeniti.
Nakon toga prisne se tipka "Pokreni simulaciju" nakon čega se simulacija pokreće i kada se izvrši u prozoru Analiza vidljiva su tri odabira prikaza dijagrama.
Slike tih dijagrama za jednu provedenu simulaciju priložene su u ovaj repozitorij.
